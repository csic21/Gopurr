# Gopurr

让连接简单一点。

Gopurr 是基于 [mihomo](https://github.com/MetaCubeX/mihomo) 的原生桌面代理客户端，支持 macOS Apple Silicon 和 Windows x64。提供订阅管理、策略组与节点切换、延迟测试、系统代理、TUN、规则编辑和 YAML 覆写，界面支持跟随系统、浅色与深色外观。

![概览](docs/render-overview-live.png)

## 安装

从 [GitHub Releases](https://github.com/csic21/Gopurr/releases/latest) 下载当前版本：

| 平台 | 安装包 | 安装方式 |
| --- | --- | --- |
| macOS Apple Silicon（M1 及后续 M 系列） | `gopurr-版本-arm64.dmg` | 打开后将 Gopurr 拖入 Applications |
| Windows 10/11 x64 | `gopurr-setup-版本-amd64.exe` | 按安装向导安装到当前用户目录 |

安装与系统验证提示见 [发布说明](docs/release-notes.md)。

## 开始使用

1. 打开 Gopurr，应用会自动启动内核。
2. 在「订阅」导入订阅链接或本地 YAML 配置，并启用所需配置。
3. 在「代理」选择策略组和节点，可先运行延迟测试。
4. 在「概览」开启系统代理。需要 TUN 时，先点击「安装服务…」并完成管理员授权，再开启 TUN。

TUN 在 macOS 使用 LaunchDaemon，在 Windows 使用系统服务与内嵌 Wintun。服务安装、升级和卸载由用户主动发起并授权。

macOS 服务使用 `/Library/PrivilegedHelperTools/io.github.gopurr.core/` 中受 root 保护的内核副本；Windows 使用 Program Files 下仅管理员与 SYSTEM 可写的服务目录。服务日志和内核缓存也保存在受保护目录。应用通过强制校验密钥的本地接口访问内核，订阅不能开启额外的 TCP、TLS、Unix socket 或 Windows 命名管道控制接口。

macOS 每次启动后首次开启系统代理时需要管理员授权。同一应用会话内的代理开关、端口调整及退出恢复会复用权限；退出时恢复接管前的配置。若恢复失败，应用保留内核并显示错误，修复后可再次退出。

## 功能

| 页面 | 能力 |
| --- | --- |
| 概览 | 实时速率、历史流量、连接与规则数量、路由模式、系统代理、TUN、DNS 与域名嗅探开关 |
| 订阅 | 链接与本地文件导入、流量与到期信息、独立更新周期、代理更新、多来源聚合、筛选与去重 |
| 代理 | 策略组与节点切换、可取消延迟测试、排序筛选、节点参数与策略组可视化编辑 |
| 连接 | 主机／进程／IP／规则搜索、会话详情、复制主机、单条与全部断开 |
| 组网 | 内置 Tailscale、连接引导、服务预设、SSH/远程桌面快捷连接、设备封禁与访问记录 |
| 规则 | 生效规则搜索、应用分流、额外规则、全局／单订阅 YAML 覆写、可复用覆写库 |
| 日志 | 级别筛选、暂停与继续、回到底部、清空 |
| 设置 | 外观、登录自启、静默启动、窗口行为、网络、DNS、域名嗅探、本地备份恢复及软件更新 |

手动策略组中，点击节点圆圈、名称、延迟或同行空白均可选择节点，也可用 Enter／空格操作；右侧测速按钮独立测试，不会切换节点。自动策略组展示内核调度的当前出口。延迟测试支持去重、并发、取消、延迟排序、名称排序和仅显示可用节点；结果反映响应延迟与连通性。

![代理与节点](docs/render-proxies.png)

在订阅卡片点击「编辑…」可修改名称、订阅链接与 User-Agent，并选择跟随全局、关闭或自定义自动更新周期。开启「使用 Gopurr 代理更新」后，通过正在运行的 Gopurr 内核下载；关闭时直接下载。保存来源设置不会替换缓存内容，点击「更新」成功后才使用新内容。本地配置只支持编辑名称及手动重新读取。

连接页支持按主机、进程、IP、规则与链路搜索，点击「详情」查看进程路径、源地址、目标地址和命中规则，并可复制主机名或断开连接。「断开全部…」会先确认。默认在切换节点时断开经过该策略组的旧连接，可在「设置 → 网络」关闭。

在「规则 → 应用分流」点击「添加应用…」，搜索并选择本机应用，为其指定直连、拦截或当前配置中的代理组，加入草稿后点击「保存应用分流」。macOS 扫描系统与用户的 Applications 目录；Windows 读取开始菜单中的程序快捷方式，其他位置可通过「选择文件…」添加。应用可逐项编辑、移除，保存前可放弃修改。

macOS 默认包含所选 `.app/Contents/` 内的 Helper、XPC 服务、登录项与更新程序，按完整路径匹配，避免命中其他应用的同名 Helper；关闭「包含应用包内的 Helper 子进程」后只匹配主程序。独立可执行程序（包括 Windows 程序）按其完整路径匹配，Helper 需单独选择添加。应用包外的共享进程不自动归属于该应用。应用移动后应重新选择新位置。

应用分流仅在规则模式下生效，流量须先进入 Gopurr；不遵循系统代理的应用通常需要 TUN。规则按「应用分流 → 额外规则 → 订阅／覆写规则」依次匹配；存在应用分流时自动启用进程识别，删除全部应用分流后恢复订阅／覆写的进程识别设置。规则变更适用于新连接，已有连接可在「连接」页断开后重建。

YAML 覆写递归合并映射、整体替换数组，应用管理的网络参数最后写入。订阅更新保留应用分流与其他自定义内容，配置校验、重载或保存失败时保留原配置与编辑草稿。应用分流也包含在本地备份中。

DNS 和域名嗅探默认跟随订阅与 YAML 覆写。在「设置 → DNS / 域名嗅探」选择「自定义」后，可调整解析服务器、Fake-IP、HTTP/TLS/QUIC 嗅探端口以及域名和地址例外，保存后重新载入运行中的内核。自定义参数适用于所有订阅，其他字段继续沿用配置；切回「跟随配置」并保存即可移除。概览的快捷开关会保存为自定义设置，TUN 开启时不能关闭内置 DNS。

## 订阅聚合、节点编辑与覆写库

在「订阅 → 新建聚合…」选择已导入的来源，调整顺序与名称前缀，可用正则表达式包含／排除节点，并选择按完整连接参数去重。预览展示节点名称和数量；保存后生成独立配置，点击「启用」才切换使用。重名节点自动加序号，原来源不会被改写。

聚合读取来源缓存中的原始 `proxies` 节点，不继承来源的规则、DNS、策略组或本地覆写；聚合自身照常应用全局及单订阅设置。含 `proxy-providers` 的来源会明确提示暂不支持。来源更新或重新导入成功后会重新聚合；「重新聚合」只读取本地缓存，需要获取新节点时应先更新来源。重建失败保留上一版聚合与运行配置，仍被聚合使用的来源不能直接删除。

在「代理 → 编辑配置…」修改当前订阅的节点名称、服务器和端口，或添加、编辑、删除策略组并调整类型与成员顺序。也可从「规则 → 按订阅」打开所选配置的编辑器。节点协议、密码和未修改字段继续沿用最新来源；改动保存为订阅覆写，不改写源文件。改名会迁移相关规则和策略引用，重复名称、循环依赖或仍被引用的删除会提示修正。来源已移除的修改可用「恢复所选项」清理。

在「规则 → YAML 覆写 → 覆写库…」新建或导入常用 YAML 模板，再在「应用顺序」中添加、排序或移除。作用范围沿用规则页选择的全局或订阅；模板改名保留已有引用，仍在使用的模板须先停用才能删除。模板库与应用顺序分别确认保存，导出仅包含所选模板的 YAML。

合并顺序为「原配置 → 全局模板（按顺序）→ 全局手写覆写 → 订阅模板（按顺序）→ 订阅手写覆写 → 节点与策略组修改 → 应用网络设置」。映射递归合并，数组整体替换；应用管理的端口、TUN 和控制接口仍受原有约束。聚合来源设置、缓存、节点修改和覆写库均包含在本地备份中。

## 多设备组网

「组网」内置 Tailscale 节点，连接 [官方托管服务](https://tailscale.com/)，无需另装官方客户端或自建服务器。在浏览器登录官方账号，多台电脑、手机、服务器可加入同一网络。

首次在「连接准备」里完成浏览器授权；「准备访问」会集中设置 Gopurr TUN、规则模式和所需系统服务，安装前说明变更并请求系统授权。只接受其他设备访问时可跳过网络准备。支持 TCP / UDP 服务访问，不提供广播发现、系统 ICMP 转发、子网路由或出口节点。

从设备行点击「连接」，可选择 SSH、远程桌面或屏幕共享，记住端口与可选的 SSH 用户名；之后直接打开本机对应客户端，最近使用的设备优先显示。快捷连接只保存连接方式，不保存密码。可按需检测指定端口，TCP 接通与服务响应分别说明；实际登录仍由客户端完成。

不同账号可点击组网页头「邀请成员」，按引导打开官方控制台生成邀请；对方接受后，在 Gopurr 登录时选择同一个网络。浏览器无法打开时，可复制控制台地址继续操作。

本机访问默认关闭。开放时选择 SSH、远程桌面或屏幕共享预设，也可填写自定义端口，确认后才生效；每个连接都核对设备身份与封禁状态。设备详情支持单独禁止访问，关闭访问会终止已有连接。授权端口转发至本机 `127.0.0.1` 的同端口服务，请保留服务自身的登录验证，并在官方控制台限制成员权限和启用设备审批。

可选「启动 Gopurr 时自动连接组网」；只恢复组网连接，本机服务访问仍保持关闭，授权失效时需主动继续登录。访问记录包含设备、所属账号、协议与时间，在本机保留最近 100 条。退出或进程终止后内嵌节点随之停止；下次连接重新关闭访问。设备密钥和访问记录不进入配置备份。

实现边界与验证方式见 [组网说明](docs/tailscale.md)。真实账号授权和跨公网多设备互访仍需实机验收。

## 外观与窗口

安装后可通过 `gopurr://install-config?url=<编码后的订阅链接>&name=<可选名称>` 从浏览器导入订阅，也兼容 `clash://install-config`。订阅地址须完整 URI 编码；应用会打开添加表单，确认后才下载，不会覆盖未完成的订阅草稿。Windows 安装器和 macOS 应用包均包含协议注册。

在「设置 → 常规 → 快捷操作」配置全局快捷键，可从其他应用显示 Gopurr、切换系统代理／TUN，或切换到规则、全局、直连模式。默认全部关闭，输入如 `Ctrl+Alt+P` 或 `CmdOrCtrl+Shift+Space`，留空可禁用；保存后立即生效，冲突或保存失败保留原绑定。关窗与轻量模式不影响快捷键，退出应用后释放。TUN 服务未准备好时打开概览提示，不会自动安装服务。备份恢复保留本机的快捷键。

点击标题栏的侧栏按钮可在左侧导航与顶部导航之间切换，也可使用 ⌘\\（Windows 为 Ctrl+\\）。导航项在 320 ms 内从纵列移动成横排，内容区同步展开；切换途中可以直接反向操作。全部八个页面仍可直接访问，布局选择自动保存，当前页面与未保存草稿保持不变。

![导航切换动效](docs/navigation-morph.gif)

在「设置 → 常规」可开启登录自启与静默启动。登录自启只影响当前用户；静默启动后内核和托盘继续运行，不创建窗口，可从菜单栏／托盘或程序坞打开。启动失败或托盘不可用时仍会显示窗口。

在「设置 → 常规 → 外观」选择跟随系统、浅色或深色。应用、侧栏和菜单栏使用统一的纯黑白蜷睡猫标记。

![浅色外观](docs/render-light-settings.png)

macOS 可选择程序坞图标的显示方式，修改后立即生效并保存：

| 选项 | 行为 |
| --- | --- |
| 隐藏 | 始终隐藏程序坞图标，左键点击菜单栏图标或选择菜单中的「显示窗口」打开界面 |
| 跟随窗口 | 打开窗口时显示，关闭窗口时隐藏 |
| 显示（默认） | 关闭窗口后保留图标，点击即可重新打开窗口 |

关闭窗口后代理继续运行。轻量模式会在设定时间后释放窗口，下次打开时重新创建；程序坞图标仍按所选偏好显示。最小化的窗口可从程序坞恢复。

macOS 菜单栏图标左键直接显示主窗口，右键打开菜单，在菜单中提供系统代理、TUN、路由模式和节点选择。Windows 托盘行为一致；Linux 面板只提供菜单，点击图标即打开菜单。需要退出应用时，使用菜单栏/托盘的「退出 Gopurr」；macOS 也支持 ⌘Q。

## 界面语言

在「设置 → 常规 → 外观 → 语言」选择「跟随系统」「简体中文」或「English」。默认跟随系统的首选语言列表；支持区域语言匹配（如 zh-CN、en-GB），没有受支持的语言时使用英文。手动切换立即生效，保存在 `prefs.json` 的 `language` 字段，重启和轻量模式重新打开窗口后仍保留。页面、编辑器、对话框、菜单与常见操作提示使用同一语言；节点名称、订阅内容、配置和内核日志保留原文。

## 软件更新

在「设置 → 维护 → 软件更新」或托盘菜单检查更新。应用默认每天检查新版本，展示更新说明，经确认后下载和安装。更新包使用固定公钥校验 Ed25519 签名，软件更新会保留订阅、规则和设置。

若更新后提示 TUN 服务版本落后，在概览页点击「重新安装…」并再次授权，即可升级服务内核。

从旧版升级到包含安全修复的版本时，已安装的 TUN 服务也需要重新安装，才能替换旧内核与安装路径；应用会根据服务安全版本提示更新。

## 本地备份与恢复

在「设置 → 维护 → 本地备份」导出 ZIP 备份，包含订阅索引与缓存配置、本地配置、规则覆写、DNS／嗅探设置和偏好。备份不加密，包含订阅链接及配置凭据，请妥善保存；不包含内核缓存、系统代理恢复记录、服务状态或配置引用的外部文件。

选择备份后会展示时间与订阅数量，确认后替换现有配置；建议先导出当前备份。恢复会校验归档和配置，内核拒绝配置或写入失败时回退原配置。本机的登录自启、当前代理端口和 TUN 开关保持原设置；恢复的本地配置直接使用备份内容，不再依赖原电脑的文件路径。

## 数据目录

| 平台 | 默认目录 |
| --- | --- |
| macOS | `~/Library/Application Support/Gopurr/` |
| Windows | `%APPDATA%\Gopurr\` |

可通过 `GOPURR_HOME` 指定其他数据目录。目录包含界面偏好、订阅索引与内容、本地配置、规则覆写、运行配置及 mihomo 缓存；这些数据保存在应用包之外。

首次启动会自动准备随安装包提供的 GeoIP／GeoSite／ASN 基础数据库，普通内核与 TUN 服务均可直接使用，无需手动下载文件。内核就绪后默认每天在后台检查所需数据库，通过当前分流线路下载并校验后替换；下载失败或内容无效时保留本地版本，一小时后重试。成功检查时间会保存，重启应用不会重复下载；切换数据库来源后会立即检查。订阅或 YAML 中显式设置的 `geo-auto-update`、`geo-update-interval` 和 `geox-url` 继续生效。

## 开发与构建

使用 Go 1.27.3。界面由 [mygo](https://github.com/egoist/mygo) 原生渲染，mihomo 内核在独立进程中运行，应用通过本地控制器 socket 与内核通信。

离线数据库的来源提交与校验和记录在 `internal/geodata/data/manifest.json`；`make update-geodata` 从 MetaCubeX 的最新 release 分支刷新快照。正式发布会自动执行刷新，已安装应用的数据库更新独立于软件发布。

```sh
git clone https://github.com/csic21/Gopurr.git
cd Gopurr
make run
```

Makefile 使用仓库内的 `.cache` 缓存，并启用 TUN 所需的 `with_gvisor` 构建标签。

| 命令 | 用途 |
| --- | --- |
| `make run` | 编译并运行 |
| `make build` | 生成 `bin/Gopurr` |
| `make test` | 运行测试与界面渲染检查 |
| `make test-native` | 在 macOS 验证原生窗口与程序坞行为 |
| `make bundle` | 生成 `bin/darwin-arm64/Gopurr.app` |
| `make icons preview-icons` | 更新运行图标与明暗背景预览 |

测试使用临时数据目录、本地测试源和控制器，不加载真实订阅或修改系统代理。发布工作流在 macOS 与 Windows 上测试、构建安装器，并验证签名更新的完整安装过程。
