# Gopurr UX / UE / UI 审查

2026-10-27。根据用户提供的真实界面、现有 Go / mygo 实现和以下上游资料审查，并落地本轮修复。

参考 [Sparkle 项目](https://github.com/xishang0128/sparkle)的开箱即用和常用配置能力、[Clash Verge Rev 扩展文档](https://github.com/clash-verge-rev/clash-verge-rev.github.io/blob/main/docs/guide/extend.md)的配置与应用设置优先级，以及[官方更新记录](https://github.com/clash-verge-rev/clash-verge-rev/releases)中的代理组筛选、排序、延迟测试和分组导航改进。实现继续使用本项目的原生控件和守护进程架构。

## 核心判断

原界面把内核数据结构直接交给用户：所有组同时展开、GLOBAL 排在最前、每个成员都是小标签，节点在多个组重复出现。这使“选一个可用节点”变成滚动寻找文字，而且分不清当前节点、组引用和普通节点。它是信息架构、操作反馈和默认行为共同造成的问题，单独换颜色无法解决。

## 操作语义

- **内核运行**：应用负责维持代理服务，默认启动。
- **系统代理**：用户选择是否将系统代理指向本应用；可设置启动时自动开启。
- **TUN**：由授权的系统服务接管系统流量，与规则 / 全局 / 直连的路由模式分别表达。
- **延迟测试**：通过待测节点请求测试地址，判断响应时间与连通性；数字单位为 ms，不能据此宣称下载速率。
- **额外规则**：按输入顺序放在最终 rules 最前面，先匹配先命中；订阅更新后保留。
- **YAML 覆写**：映射递归合并，数组整体替换；最后应用程序管理的端口、模式、TUN 等设置。控制器连接和密钥不接受用户覆写。
- **保存**：只有通过配置校验、运行中的内核接受配置、原子文件写入成功后才显示成功；失败保留草稿。

## 验证方式

`rtk go test ./...` 覆盖配置合并与规则校验、控制器协议、取消测试、配置回滚、偏好迁移、界面交互和离屏渲染。大列表检查使用 2000 个节点，确保只构建可见行。渲染样张位于 docs/render-*.png，包含 1060×720 标准窗口和 840×560 最小窗口。

测试使用临时目录、假控制器和本地源验证行为。它能验证客户端的连通测试流程；真实订阅节点在用户当前网络上的可用性仍需实际测量。

本轮最终结果：192 项测试通过；生成并检查 22 张离屏截图；`make build bundle` 成功，应用包位于 `bin/darwin-arm64/Gopurr.app`。另用隔离的临时配置实际启动应用，未设置启动环境开关，验证默认拉起内核、本地 HTTP 请求经过混合代理、控制器返回非零延迟（本地测试源 33 ms），并正常退出。此烟测没有更改系统代理，也未操作用户订阅。

## UI 精修复验 · 2026-10-27

用户将视觉品质作为本轮重点。新增 [UI 规范](../DESIGN.md)，并在项目 AGENTS.md 中要求 UI 修改必须经过看图验收。

- 用石墨灰表面、柔和蓝色选中态和更清晰的字号层级统一界面。辅助文字从原来的 9–10 提升到 11–12；指标数字与单位分层。
- 导航、状态、搜索清空和节点测试统一为官方 Lucide SVG，许可随文件保存。侧栏仅强调当前页，保留原生方向键和选中语义。图标按钮有名称、提示、焦点环、悬停和按下反馈。
- 概览指标合并为一组，图表降低填充浓度；小窗口缩短图表，系统代理与 TUN 开关保持首屏可见。节点和连接使用统一容器与分隔线，减少重复卡片和大按钮。
- 订阅表单补齐可见标签，来源与长名称单行省略并提供完整提示；设置分类只占内容所需宽度。
- 品牌重新绘为 SVG，保留猫耳、圆眼与门牙。Dock、侧栏和菜单栏采用同源图形；菜单栏图标验证黑色像素、透明背景与眼睛/门牙镂空。`make preview-icons` 可重现明暗背景和小尺寸检查图。

## 策略组顺序与滚动条 · 2026-10-27

策略组导航为滚动条和拖动命中区域预留 16 像素，保留原有卡片宽度，避免滚动条叠在选中边框和长文字上。截图夹具扩充为十个策略组，新增滚动到底部并选中长名称策略组的场景；交互检查覆盖默认选中、末项点击及拖动滚动条返回顶部。

验证：217 项测试、14 个包通过；更新并查看 124 张截图，覆盖明暗外观与 1060×720 / 840×560 窗口，另查看代理页原尺寸截图确认选中框、滚动条、长名称与底部统计的位置。`make build bundle` 成功，应用包位于 `bin/darwin-arm64/Gopurr.app`。
