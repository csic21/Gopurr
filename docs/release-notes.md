Gopurr 0.6.33 重做桌面八页的视觉层级与密度，修复浅色/深色切换后的按钮配色。

- 去掉标题栏「工作区 › 页面」面包屑与整页卡片，改为页头、分组表面与 1 像素分隔线；控件统一 28 高，设置行 44，列表行 46–52，页标题 20。
- 概览改为连接面板（接管状态、出口、实时速率、统计与主切换）加网络控制分组；订阅、代理、连接、日志、规则、组网使用共享分组与行，行内次要操作改为文字按钮，危险操作只使用危险色文字。
- 设置改为单行分段标签与设置行，网络、延迟、维护、DNS/嗅探和诊断重新排版，保存区固定在底部；连接表头与数值列对齐，日志行更紧凑，空状态在列表区域居中。
- 修复 NSH 原生按钮内容在浅色/深色切换后沿用旧调色板的问题：外观变化时重建页面栈，按钮文字立即使用当前配色。
- 新增空数据、设置各分类与规则标签的原生截图入口，更新 1060×720 / 840×560 明暗全部截图。
