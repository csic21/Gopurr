Gopurr 0.2.0 补齐启动、连接管理、订阅编辑和本地备份流程，保持现有原生界面风格，并新增 DNS 与域名嗅探设置。

- **登录自启与静默启动**：在「设置 → 常规」开启，支持当前用户登录后自动运行。静默启动时内核和托盘照常运行，无需创建窗口；启动异常时仍显示窗口。
- **连接管理**：支持按主机、进程、IP、规则和链路搜索，查看进程路径、源地址、目标地址与命中规则，断开单条或全部连接。切换节点默认只清理经过该策略组的旧连接，可在「设置 → 网络」关闭。
- **订阅编辑**：支持名称、地址、User-Agent、独立更新周期和通过 Gopurr 代理更新。修改来源时保留缓存；下载或内核重载失败时保留原配置。
- **本地备份与恢复**：在「设置 → 维护」导出订阅、规则、DNS／嗅探和偏好的 ZIP 备份。恢复前展示时间和订阅数量，失败时回退，并保留本机登录自启、当前代理端口和 TUN 开关。备份不加密，请妥善保管其中的订阅链接和凭据。
- **DNS 与域名嗅探**：新增设置页及概览快捷开关，支持解析服务器、Fake-IP、HTTP／TLS／QUIC 嗅探端口与例外列表。默认跟随配置，自定义设置保存后热重载，失败时保留原配置和草稿。

macOS Apple Silicon（M1 及后续 M 系列）下载 `gopurr-版本-arm64.dmg`，打开后将 Gopurr 拖入 Applications。Windows 10/11 x64 下载 `gopurr-setup-版本-amd64.exe`，按向导安装。

在「设置 → 维护 → 软件更新」检查新版本。应用每天自动检查，确认后才下载和安装；更新包使用 Ed25519 签名校验。TUN 服务需在概览页安装，macOS 通过管理员密码、Windows 通过 UAC 授权；软件升级后若提示服务需要更新，点击「重新安装」。

本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 证书，系统可能提示无法验证开发者。确认下载来自本仓库后，macOS 可在「系统设置 → 隐私与安全性」允许打开，Windows 可在 SmartScreen 中查看发布信息。

`SHA256SUMS` 用于校验安装包与更新文件。`update-*.json` 和 `.tar.gz` 由应用内更新器使用，无需手动安装。
