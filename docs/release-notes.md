Gopurr 0.6.23 将 macOS 正式客户端切换为 NSH 八页桌面，保留已有数据与更新信任链。

- Android 支持 Android 9 及以上的 arm64-v8a、x86_64 设备，提供连接、节点、订阅和设置四个入口，通过系统 VPN 授权、前台服务和 TUN 接入设备流量。
- 支持订阅链接、本地文件及粘贴 YAML 导入，配置启用、来源编辑、更新与删除，规则／全局／直连模式、节点选择、测速、流量和诊断日志；可选择全部应用、仅选中应用或排除选中应用进入 VPN。
- 路由模式和按订阅保存的手选节点跨进程重启恢复；重新打开应用仍需明确连接。取消授权、快速重连和旧任务清理按连接代次隔离，订阅下载和测速不阻塞状态查询与断开。
- 桌面与手机共用配置应用、订阅导入／更新及失败恢复事务；桌面退出会等待正在提交的配置操作，避免迟到的重载重新启动内核。
- macOS 使用 NSH 八页桌面及主要编辑器，沿用原应用身份、订阅、偏好、规则与覆写、组网身份和系统服务。首次接管数据前保存私有快照；Windows 继续使用现有桌面界面。
- macOS 旧版与 NSH 更新入口指向同一签名整包，继续使用原 Ed25519 公钥；更新等待窗口与后台退出后替换应用并启动新宿主。发布前验证旧版升级、错误签名拒绝、NSH 后续更新与数据保留。
- 发布流程对 Android APK 关闭调试，验证固定签名证书、版本、原生库与 16 KB 对齐；所有平台成功后统一发布，下载文件纳入 SHA256SUMS。
- Android 未连接时也可浏览和搜索已保存节点；新增自适应启动器图标、通知显示偏好与两行实时流量通知，支持点击返回连接页及直接断开，熄屏暂停速率刷新。

下载：

- Android ARM64 手机／平板：gopurr-0.6.23-android-arm64-v8a.apk。
- Android x86_64 设备／模拟器：gopurr-0.6.23-android-x86_64.apk。
- macOS 12 及以上 Apple Silicon：gopurr-0.6.23-arm64.dmg。
- Windows 10/11 x64：gopurr-setup-0.6.23-amd64.exe。

Android 使用独立应用数据目录。已有开发包与正式包签名不同，首次安装正式包前需卸载开发包，卸载会删除其应用数据；后续正式 APK 使用相同证书，可覆盖升级。首次连接需同意系统 VPN 授权，暂不支持 Always-on VPN 或开机自动连接；长时间后台运行、Wi-Fi／蜂窝切换及厂商电池策略仍需真机验收。iOS VPN 不包含在本次发布中。

桌面升级保留原有订阅与偏好，也可在「设置 → 维护 → 软件更新」检查更新，更新包继续通过原 Ed25519 公钥校验。本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 证书，系统可能提示无法验证开发者。请确认下载来自本仓库，并用 SHA256SUMS 校验下载文件。
