Gopurr 0.6.32 修复桌面列表内存增长、代理页自滚动和应用分流添加失败。

- 修复每秒刷新状态时，订阅、策略组和访问记录等列表被整表重建，macOS 窗口内存涨到约 1.1 GB 的问题。列表按稳定身份复用原行，内容和选中状态仍实时更新。
- 已经涨上去的内存不会自动退回，重新打开窗口后恢复正常。
- 修复代理页在刷新后自行滚动：节点列表只在成员顺序或类型真实变化时更新，延迟和选中状态仍实时刷新，已滚动到的位置保持不动。
- 修复应用分流选择应用后弹窗直接消失、编辑应用分流没有出现的问题；现在选择与编辑复用同一原生弹窗，可以继续设置出口和辅助进程并加入草稿。
- 增加代理列表跨刷新滚动保持，以及从添加应用到保存分流的交互回归。
- 保留 0.6.31 的软件更新弹窗稳定性修复，以及既有订阅、偏好、组网身份和更新公钥。
