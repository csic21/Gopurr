Gopurr 0.2.2 修复 macOS TUN 服务无法启动、系统代理失效和退出卡顿，建议所有 macOS 用户升级。

- **TUN 服务启动**：安装时把 GeoIP／GeoSite 数据预置到受保护的服务目录，首次启动不再在代理不可用时从 GitHub 下载；缺少数据时会直接失败退出。
- **服务自恢复**：LaunchDaemon 改为崩溃后由 launchd 自动重启（`KeepAlive`，30 秒节流），不再一次失败就一直停着。
- **失败原因可见**：安装时把受保护的守护进程日志复制到用户目录，概览页显示真实报错，不再一律提示「内核尚未获得管理员权限」。
- **系统代理授权**：先直接写入系统代理，只有在 macOS 拒绝时才弹出管理员授权；代理已经指向本应用时，启动不再重复索要密码。
- **退出不再卡死**：没有授权会话时也能直接还原系统代理，退出不会被「权限会话已断开」挡住；代理恢复失败仍会保留恢复记录并重试。
- **TUN 开关恢复**：服务修复后，概览页自动把此前开启的 TUN 重新打开。

**已安装 TUN 服务的用户：更新应用后，请在概览页点击「重新安装…」并完成一次管理员授权，让新脚本替换旧守护进程并预置地理数据。**

macOS Apple Silicon（M1 及后续 M 系列）下载 `gopurr-版本-arm64.dmg`，打开后将 Gopurr 拖入 Applications。Windows 10/11 x64 下载 `gopurr-setup-版本-amd64.exe`，按向导安装。

在「设置 → 维护 → 软件更新」检查新版本。应用每天自动检查，确认后才下载和安装；更新包使用 Ed25519 签名校验。TUN 服务需在概览页安装，macOS 通过管理员密码、Windows 通过 UAC 授权；软件升级后若提示服务需要更新，点击「重新安装」。

本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 证书，系统可能提示无法验证开发者。确认下载来自本仓库后，macOS 可在「系统设置 → 隐私与安全性」允许打开，Windows 可在 SmartScreen 中查看发布信息。

`SHA256SUMS` 用于校验安装包与更新文件。`update-*.json` 和 `.tar.gz` 由应用内更新器使用，无需手动安装。
