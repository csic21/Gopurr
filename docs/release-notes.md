Gopurr 0.6.17 优化大订阅的概览刷新、macOS 后台状态读取、连接列表和节点切换。

- 概览的 DNS／嗅探状态按配置版本缓存，在后台计算变更后的配置，避免每秒重新合成和解析完整 YAML。
- macOS 使用系统框架直接读取完整代理状态，减少后台健康检查反复启动系统命令的开销；保留关闭协议的地址、PAC、自动发现和绕过规则。
- 桌面与远程 Web 共享连接快照，合并并发读取；连接页后台刷新和断开，相同快照的重复搜索复用结果。内核新增经过认证的轻量连接计数接口。
- 窗口和托盘节点切换移到后台，连续选择保留最后一次等待请求；旧连接清理仅针对所选策略组，最多 8 路并发，总预算 10 秒。
- 内核验证已接受配置的指纹，相同配置且实际运行状态就绪时跳过重复重载；手动「重新加载配置」仍强制执行，保留配置失败回滚。

本机 Apple M4 微基准：10 万规则下未变配置的概览状态重复读取从约 298 ms 降至约 0.0004 ms；macOS 完整代理状态读取从约 129 ms 降至约 0.57 ms。上述为特定函数的微基准，不代表首次加载耗时、整机能耗或与其他客户端的比较。测量口径及复现命令见 [性能说明](https://github.com/csic21/Gopurr/blob/v0.6.17/docs/performance.md)。

**普通应用升级不需要重装兼容的系统服务。** 已安装服务继续使用独立内核副本，缺少新接口时自动走兼容路径。要启用轻量连接计数和配置指纹去重，可在「概览 → 网络详情」主动更新服务并完成管理员授权；订阅与设置保留。仅使用普通内核的用户无需安装服务。

macOS Apple Silicon 下载 gopurr-0.6.17-arm64.dmg；Windows 10/11 x64 下载 gopurr-setup-0.6.17-amd64.exe。也可在「设置 → 维护 → 软件更新」检查更新，更新包通过 Ed25519 签名校验。

本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 证书，系统可能提示无法验证开发者。请确认下载来自本仓库。SHA256SUMS 用于校验下载文件。
