Gopurr 0.6.10 集中修复 Windows 系统代理、TUN 与内核的启停和异常恢复，并让概览显示实际网络状态。

**升级后请重新安装一次旧版 TUN 服务。** Windows 和 macOS 上此前安装过 TUN 系统服务的用户，请安装新版应用后，在「概览 → TUN 模式」点击「重新安装…」，完成 UAC／管理员授权，等待服务就绪后再开启 TUN。订阅和设置会保留。

本版控制接口升级至 2，普通应用更新不会自动替换已安装服务中的旧内核；重新安装后才能使用新的实际状态检测和恢复机制，以及 Windows 服务启停权限与内核专用防火墙规则。从未安装服务、仅使用系统代理的用户无需安装 TUN 服务。

- **Windows 系统代理恢复更完整**：改用 WinINet 连接选项 API，保存并恢复手动代理、PAC、自动发现及绕过规则。应用崩溃后由独立进程归还设置，并尊重用户或其他程序后续的修改。
- **检测实际接管状态**：分别检查控制接口、本地代理握手、TUN 网卡和地址、自动路由及内置 DNS。配置重载后仍需验证实际状态，失败时恢复上一份文件和运行配置。
- **更可靠的启停与异常恢复**：TUN 和服务操作在后台完成，修复安装取消、失败及卸载时的内核交接；异常退出与本地入口故障采用有限次数恢复，主动停止后不自动重启，退出时等待正在执行的网络操作完成。
- **Windows 服务生命周期修复**：支持所属用户启停、明确的「重启服务」操作和 SCM 崩溃恢复；修复启动阶段立即停止／重启的竞态，以及代理恢复互斥锁的复用问题。安装时添加内核专用防火墙规则，卸载时清理；TUN 默认接管 UDP/TCP DNS 并启用严格路由。
- **概览更直观**：直接显示代理与 TUN 是否就绪、等待检测或需要处理；IP、端口、作用范围和具体错误收进「网络详情」。

Windows 原生 CI 已覆盖系统代理真实请求与崩溃恢复、TUN 实际 DNS／自动路由流量、服务停止／启动／重启、内核被强制结束后的恢复，以及服务升级。

macOS Apple Silicon（M1 及后续 M 系列）下载 `gopurr-0.6.10-arm64.dmg`，打开后将 Gopurr 拖入 Applications。Windows 10/11 x64 下载 `gopurr-setup-0.6.10-amd64.exe`，按向导安装。

也可在「设置 → 维护 → 软件更新」检查新版本，更新包通过 Ed25519 签名校验。应用更新完成后，已安装过旧版 TUN 服务的用户仍需按上述步骤重新安装服务一次。

本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 证书，系统可能提示无法验证开发者。确认下载来自本仓库后，macOS 可在「系统设置 → 隐私与安全性」允许打开，Windows 可在 SmartScreen 中查看发布信息。

`SHA256SUMS` 用于校验安装包与更新文件。`update-*.json` 和 `.tar.gz` 由应用内更新器使用，无需手动安装。
