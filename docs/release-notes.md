Gopurr 0.6.0 新增订阅聚合、节点与策略组编辑、可复用覆写库、一键导入和全局快捷键。

- **订阅聚合**：按顺序组合已导入来源，支持名称前缀、正则包含／排除、连接参数去重及结果预览。来源更新或重新导入后自动重建，失败保留上一版；保存后可主动启用，不改写来源配置。
- **节点与策略组编辑**：在「代理 → 编辑配置…」修改节点名称、服务器和端口，管理策略组类型及成员顺序。改动保存为单订阅覆写，未修改的凭据和高级参数沿用最新来源；名称引用自动迁移，冲突、循环与仍被引用的删除会提示修正。
- **可复用覆写库**：在「规则 → YAML 覆写 → 覆写库…」新建、编辑或导入 YAML 模板，在全局或单订阅中排序应用；支持本地导出、引用保护和独立草稿保存。
- **一键导入订阅**：支持 `gopurr://` 和 `clash://install-config`，打开添加表单确认后下载，不覆盖未完成的订阅草稿。
- **全局快捷键**：在「设置 → 常规 → 快捷操作」配置显示窗口、系统代理／TUN 开关与三种路由模式；默认关闭，冲突或保存失败保留原绑定，关窗与轻量模式下仍可使用。
- **配置与恢复**：本地备份包含聚合关系、缓存、节点修改和覆写库；来源重新导入、配置激活和编辑保存支持失败回滚，保留当前与非当前配置的规则隔离。

聚合当前读取原始来源缓存中的 `proxies` 节点，不继承来源规则、DNS、策略组或来源覆写；含 `proxy-providers` 的来源暂不支持。「重新聚合」只读取本地缓存，获取新节点时应先更新来源。聚合配置自身照常应用全局与单订阅覆写。

macOS Apple Silicon（M1 及后续 M 系列）下载 `gopurr-0.6.0-arm64.dmg`，打开后将 Gopurr 拖入 Applications。Windows 10/11 x64 下载 `gopurr-setup-0.6.0-amd64.exe`，按向导安装。

在「设置 → 维护 → 软件更新」检查新版本。更新包通过 Ed25519 签名校验。若提示 TUN 服务需要更新，在概览页点击「重新安装…」并完成管理员授权。

本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 证书，系统可能提示无法验证开发者。确认下载来自本仓库后，macOS 可在「系统设置 → 隐私与安全性」允许打开，Windows 可在 SmartScreen 中查看发布信息。

`SHA256SUMS` 用于校验安装包与更新文件。`update-*.json` 和 `.tar.gz` 由应用内更新器使用，无需手动安装。
