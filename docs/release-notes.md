Gopurr 0.6.70 全面简化移动端日常交互，将手机端界面统一到「现代仪器台」规范，完成 Android 后台组网隧道与代理 VPN 的端到端解耦，并升级依赖修复安全漏洞。

- 移动端交互全面简化：保持底部 4 标签导航并在非首页释放顶部品牌栏空间；连接页一屏呈现连接状态、当前出口直达节点、快速切换配置、实时速率与累计统计读数卡以及独立「设备组网」入口卡；统一原生分段控件、底部面板（宽屏自动居中弹窗）、分组列表行与左上返回顶栏。
- 连接态安全切配置与双轨状态表达：在 VPN 已连接状态下切换其他订阅时，经确认后严格按序执行「断开 → 激活 → 重连」，断开失败立即中止；清晰区分 Android 后台仅组网隧道、等待组网 VPN 权限与代理 VPN 连接状态，未开代理或断开代理时设备组网保持可用。
- 节点、订阅、设置与组网流程提效：节点页提供柔和策略组胶囊、多组快选面板、无框延迟胶囊及批量测速进度与中止；订阅页将表单与菜单收进底部面板并展示更新时间；设置页收拢为 3 组一屏可见列表并将通知与更新详情放入面板；移动端组网页重组为「设备 / 本机共享 / 设置」三段，设备操作与端口探测收进详情面板并支持自动唤起浏览器登录。
- 安全依赖更新：升级 `github.com/gobwas/ws` 至 `v1.5.0`，修复 `GO-2026-6940` 漏洞。
