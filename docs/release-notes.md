Gopurr 0.6.34 以「安静的精密仪器」重做桌面视觉与交互，概览变为可悬停检查的连接控制台。

- 统一桌面八页的排版与控件：页标题 20/600、分组标签 12/600、正文 13、辅助 11.5、表头 10.5；速率与数字使用等宽数字，控件、分组与弹窗共用 6/10/12 圆角和 120–140 ms 颜色过渡。
- 概览重构为连接控制台：左缘 2 像素接管状态竖线，出口、策略组、峰值、上下行与本地代理健康分层排列；速率拆分数值与单位，流量图吸收剩余高度并支持悬停取样检查，轴行显示「N 秒前」与上下行读数。
- 侧栏品牌区、导航选中片与标题栏内核状态胶囊重绘；选中项增加左缘强调竖线，标题栏状态只表达内核运行状态。
- 分段选择改为凹陷轨道与抬起的选中片；页头动作改用边框按钮，行内动作保持文字按钮；悬停、按下与焦点态在八页统一。
- 订阅、代理、连接、日志、规则、组网与设置补齐列表层级：策略组选中标记、节点与连接选中竖线、订阅「使用中」标签、日志级别竖线、46–52 高的行与对齐的表头；编辑器列表改用分组表面，截断说明提供完整提示。
- 补齐 1060×720 / 840×560 明暗、中英文、展开/收起标题栏、编辑器、弹窗、空状态、组网与 Windows 悬停态截图。
