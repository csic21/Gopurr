Gopurr 0.5.0 新增中英文国际化、每订阅覆写、连接规则与连通诊断，并保留 v0.4.4 的组网安全修复。

- **界面语言**：默认跟随系统首选语言，不支持时使用英文。在「设置 → 常规 → 外观 → 语言」选择跟随系统、简体中文或 English，立即生效并保存。覆盖八个页面、两种导航布局、菜单和编辑器；节点名、订阅内容、配置与内核日志保留原文。
- **每订阅覆写**：独立设置额外规则、YAML 和 DNS，支持全局／订阅范围切换、草稿保留和最终配置预览；订阅更新与备份恢复保留覆写。
- **从连接创建规则**：按域名、进程或 IP 创建分流规则，选择全局或当前订阅，可在保存后断开原连接以重新匹配。
- **连通诊断**：逐项检查内核、代理端口、系统代理、系统／内核 DNS、DIRECT 出站与代理请求，支持取消和复制脱敏报告。
- **兼容性**：保留应用分流、Tailscale 内置组网、侧栏／顶部导航、原配置顺序、异步退出和系统代理恢复；订阅覆写重新应用时继续保留当前会话的组网隔离路由。

macOS Apple Silicon（M1 及后续 M 系列）下载 `gopurr-0.5.0-arm64.dmg`，打开后将 Gopurr 拖入 Applications。Windows 10/11 x64 下载 `gopurr-setup-0.5.0-amd64.exe`，按向导安装。

在「设置 → 维护 → 软件更新」检查新版本。更新包通过 Ed25519 签名校验。若提示 TUN 服务需要更新，在概览页点击「重新安装…」并完成管理员授权。

本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 证书，系统可能提示无法验证开发者。确认下载来自本仓库后，macOS 可在「系统设置 → 隐私与安全性」允许打开，Windows 可在 SmartScreen 中查看发布信息。

`SHA256SUMS` 用于校验安装包与更新文件。`update-*.json` 和 `.tar.gz` 由应用内更新器使用，无需手动安装。
