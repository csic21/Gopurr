Gopurr 0.6.11 修复 macOS TUN 运行中被误报为“服务未就绪”，并完善系统代理、路由验证与权限管理。

**普通应用更新不需要重装兼容的系统服务。** 本版服务接口升级至 3；此前安装过服务的用户需在「概览 → TUN 模式 → 更新服务…」完成一次管理员授权，才能使用本版的完整路由检测、代理授权复用和服务重启能力。订阅与设置保留。后续兼容的应用更新、日常代理／TUN 开关与应用重启不需要重复这一步；实际替换特权内核、修复安装或卸载服务时，系统仍会请求管理员授权。

- **修复 TUN 误报**：普通界面进程探测 root 服务时，系统返回“没有发送信号的权限”，此前被误当成服务退出。现在正确识别存活状态，权限能力与运行健康分开，短暂探测超时也不会直接变成重装提示。
- **复用已有授权**：macOS 已安装系统服务时，系统代理通过经过认证的受限会话复用授权。界面异常退出后归还设置，服务崩溃后通过受保护的恢复记录重试；不接受任意命令或可执行路径。
- **代理状态与恢复更完整**：核对 HTTP、HTTPS、SOCKS、PAC、自动发现和绕过设置，验证恢复结果，并尊重用户或其他客户端后续的修改。
- **TUN 验证更严格**：按内核实际生成的路由计划检查完整覆盖，包括 IPv6、自定义网段、排除范围与主机路由，避免仅有一条直连路由时仍显示接管成功。
- **网络操作保持响应**：系统代理开关、异常恢复、服务交接及网络设置保存均在后台执行。端口修改失败时，按顺序恢复配置、监听器与系统代理。
- **区分恢复与升级**：提供独立的更新、重启和修复入口。兼容服务的版本差异只在网络详情提供可选升级，不遮盖实际接管状态。

macOS Apple Silicon（M1 及后续 M 系列）下载 `gopurr-0.6.11-arm64.dmg`，打开后将 Gopurr 拖入 Applications。Windows 10/11 x64 下载 `gopurr-setup-0.6.11-amd64.exe`，按向导安装。

也可在「设置 → 维护 → 软件更新」检查新版本，更新包通过 Ed25519 签名校验。无需安装系统服务也可独立使用系统代理；macOS 系统策略要求时会单独请求当前会话的授权。

本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 证书，系统可能提示无法验证开发者。请确认下载来自本仓库。`SHA256SUMS` 用于校验安装包与更新文件；`update-*.json` 和 `.tar.gz` 由应用内更新器使用，无需手动安装。
