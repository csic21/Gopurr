Gopurr 0.6.9 修复 TUN／服务内核在健康检查恢复时被误重启的问题，并让 Windows 托盘菜单始终显示当前状态。

- **不再误杀运行中的内核**：健康检查恢复系统代理时直接重新开启，不再经过启动内核路径；响应较慢（0.7–2.5 秒）但仍在运行的内核不会被回收重启，已安装服务慢响应也不再被判定启动失败。
- **可取消的自动恢复**：等待内核恢复期间，概览开关与托盘显示「等待内核恢复」；关闭开关、取消托盘勾选、快捷键、在设置中关闭「启动时自动开启系统代理」或停止内核都会取消。自动恢复不改写该偏好。
- **更准确的提示**：内核真实退出时提示需要手动重新启动；不再覆盖更具体的启动失败原因。订阅下载期间也能识别内核真实退出。
- **Windows 托盘实时状态**：右键菜单每次打开都按当前状态生成，不再显示启动时的系统代理与 TUN 快照。

macOS Apple Silicon（M1 及后续 M 系列）下载 `gopurr-0.6.9-arm64.dmg`，打开后将 Gopurr 拖入 Applications。Windows 10/11 x64 下载 `gopurr-setup-0.6.9-amd64.exe`，按向导安装。

在「设置 → 维护 → 软件更新」检查新版本。更新包通过 Ed25519 签名校验。仅在安全／控制器版本不兼容时需要在概览页「重新安装…」并完成管理员授权；仅应用版本更新时一般不必重装服务。

本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 证书，系统可能提示无法验证开发者。确认下载来自本仓库后，macOS 可在「系统设置 → 隐私与安全性」允许打开，Windows 可在 SmartScreen 中查看发布信息。

`SHA256SUMS` 用于校验安装包与更新文件。`update-*.json` 和 `.tar.gz` 由应用内更新器使用，无需手动安装。
