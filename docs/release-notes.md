Gopurr 0.6.20 优化开关、保存和窗口交互，并完善本地节点编辑。

- 代理页支持新增本地节点及编辑协议、认证和高级参数。只保存修改字段，节点改名同步引用，策略组原成员继续跟随订阅更新。
- 系统代理的启动策略与当前开关分别设置；首次关闭窗口时说明应用将继续在后台运行。
- DNS／嗅探支持「跟随配置、始终开启、保持关闭」，明确作用范围；调整开关后，订阅中的其他参数仍可正常更新。
- DNS、嗅探、规则和编辑器保存移至后台，失败保留草稿并回退运行配置；节点与聚合编辑器增加未保存修改保护，网络／测试设置增加「放弃修改」。
- 成功提示自动消失且不挤压布局；服务维护移入详情，删除操作单独分隔，完善中英文及小窗口布局。
- 新配置的 Web 控制台默认仅监听本机，已有监听设置保留。

升级保留原有订阅与偏好。系统代理默认按上次手动开关状态启动，也可在常规设置中改为始终开启或保持关闭。

macOS Apple Silicon 下载 gopurr-0.6.20-arm64.dmg；Windows 10/11 x64 下载 gopurr-setup-0.6.20-amd64.exe。也可在「设置 → 维护 → 软件更新」检查更新，更新包通过 Ed25519 签名校验。

本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 证书，系统可能提示无法验证开发者。请确认下载来自本仓库。SHA256SUMS 用于校验下载文件。
