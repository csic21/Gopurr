Gopurr 0.4.3 新增组网成员邀请入口，并修复登录按钮点击后无法取得授权链接的问题。

- 组网页头新增「邀请成员」：查看当前网络与跨账号加入步骤，打开 Tailscale 官方成员邀请页面。对方接受邀请后，用自己的账号登录并选择同一个网络即可；浏览器打开失败时支持复制控制台地址。
- 修复内置节点绕开当前 TUN 网络路径导致的登录请求卡住，改为沿用系统网络。连接准备显示连接进度，支持取消；等待超时会提示检查网络或代理设置。

同时保留此前的内置多设备组网与快捷访问能力：

- 直接连接 Tailscale 官方托管服务，在浏览器完成账号授权；Gopurr 内置组网节点，无需另装官方客户端或自建服务器。
- 三步引导集中完成登录、访问准备和可选的本机服务授权。TUN、规则模式与所需系统服务在原页面确认，取消后保留连接草稿，失败可重试。
- SSH、远程桌面和屏幕共享提供服务预设。记住连接方式后，可从设备列表直接打开本机对应客户端，最近使用的设备优先显示；Gopurr 不保存密码。
- 支持按需检测指定端口，并区分 TCP 接通与服务响应；实际身份验证与登录由客户端完成。
- 本机入站访问默认关闭。开放服务须明确确认端口；设备详情可单独封禁，关闭访问会终止已有连接。可选启动自动连接只恢复组网，仍保持入站访问关闭。
- 首次写入组网访问记录前收紧目录权限，Windows 使用实际 ACL 限制本地文件访问。
- 本机访问记录关联设备与所属账号，保留最近 100 条 TCP / UDP 记录，包含短连接；账号标识设备归属。

组网当前支持按虚拟 IP 访问 TCP / UDP 服务；不提供广播发现、系统 ICMP 转发、子网路由或出口节点。SSH、远程桌面和屏幕共享需对方启动相应服务，并保留服务自身的登录保护。使用方式、记录范围和验证边界见[组网说明](https://github.com/csic21/Gopurr/blob/v0.4.3/docs/tailscale.md)。

macOS Apple Silicon（M1 及后续 M 系列）下载 `gopurr-版本-arm64.dmg`，打开后将 Gopurr 拖入 Applications。Windows 10/11 x64 下载 `gopurr-setup-版本-amd64.exe`，按向导安装。

在「设置 → 维护 → 软件更新」检查新版本。应用每天自动检查，确认后才下载和安装；更新包使用 Ed25519 签名校验。TUN 服务可从组网页内的「准备访问」或概览页安装，macOS 通过管理员密码、Windows 通过 UAC 授权；软件升级后若提示服务需要更新，点击「重新安装」。

本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 代码签名证书，系统可能提示无法验证开发者。确认下载来自本仓库后，macOS 可在「系统设置 → 隐私与安全性」允许打开，Windows 可在 SmartScreen 中查看发布信息。

`SHA256SUMS` 用于校验安装包与更新文件。`update-*.json` 和 `.tar.gz` 由应用内更新器使用，无需手动安装。
