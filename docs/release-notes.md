Gopurr 0.6.18 修复 macOS 后台健康检查的原生内存泄漏。

- 系统代理状态读取现在会及时释放系统框架内部生成的临时对象，避免长时间运行后内存持续积累。此问题也会影响轻量模式关闭窗口后的常驻内存。
- 健康检查频率、代理设置和故障恢复策略保持不变，代理与 TUN 继续正常工作。
- 新增原生堆回归检查：连续读取 1000 次，修复前新增 1000 个临时枚举器，修复后没有积累。轻量模式的隔离测量及口径见 [性能说明](https://github.com/csic21/Gopurr/blob/v0.6.18/docs/performance.md)。测量值不代表真实订阅环境的内存目标。

**更新后需重新启动应用，才能使用修复并清除旧进程已经积累的内存。无需重新安装兼容的 TUN 系统服务，订阅和设置保留。**

macOS Apple Silicon 下载 gopurr-0.6.18-arm64.dmg；Windows 10/11 x64 下载 gopurr-setup-0.6.18-amd64.exe。也可在「设置 → 维护 → 软件更新」检查更新，更新包通过 Ed25519 签名校验。

本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 证书，系统可能提示无法验证开发者。请确认下载来自本仓库。SHA256SUMS 用于校验下载文件。
