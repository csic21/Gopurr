Gopurr 0.6.8 修复内核健康检查误判导致系统代理被自动关闭、且内核恢复后不再开启的问题。

- **更稳的健康检查**：单次探测超时放宽至 2.5 秒，需连续约 10 秒（至少 4 次）无响应才判定内核异常；内核启动／重载、订阅更新、服务安装期间不判定；应用自启动的内核以真实进程退出为准。
- **临时恢复，不改偏好**：健康检查临时恢复系统代理时不再关闭「启动时自动开启系统代理」；内核恢复响应后自动重新开启系统代理并清除提示。手动在概览／托盘／快捷键切换或停止内核仍照常记住。

macOS Apple Silicon（M1 及后续 M 系列）下载 `gopurr-0.6.8-arm64.dmg`，打开后将 Gopurr 拖入 Applications。Windows 10/11 x64 下载 `gopurr-setup-0.6.8-amd64.exe`，按向导安装。

在「设置 → 维护 → 软件更新」检查新版本。更新包通过 Ed25519 签名校验。仅在安全／控制器版本不兼容时需要在概览页「重新安装…」并完成管理员授权；仅应用版本更新时一般不必重装服务。

本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 证书，系统可能提示无法验证开发者。确认下载来自本仓库后，macOS 可在「系统设置 → 隐私与安全性」允许打开，Windows 可在 SmartScreen 中查看发布信息。

`SHA256SUMS` 用于校验安装包与更新文件。`update-*.json` 和 `.tar.gz` 由应用内更新器使用，无需手动安装。
