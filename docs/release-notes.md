Gopurr 0.3.0 带来「连接优先」概览、统一的七页界面和「轻柔流动」动效，并新增按应用分流。

- **连接优先概览**：实际接管状态、当前出口、最近延迟与快捷切换集中呈现，旁边显示上下行速率和趋势；嵌套策略组解析实际出口，自动调度组明确区分。840×560 下保留系统代理、TUN、DNS 和域名嗅探全部开关。
- **全页统一**：订阅优先展示当前配置，代理页聚焦策略组与本组测试，连接详情在宽窗口用侧栏、小窗口用弹窗；规则、日志和设置统一排版与操作层级。
- **轻柔流动**：页面轻升、弹窗柔和进入与淡出，按钮和选中状态平滑衔接，开关自然滑动；出口、速率与流量曲线轻柔更新。操作立即生效，静止后停止动画，支持系统减少动态效果。
- **应用分流**：在「规则 → 应用分流」搜索或手动选择应用，指定直连、拦截或代理组，支持编辑草稿和统一保存。macOS 默认覆盖应用包内 Helper、XPC 与更新程序，也可只匹配主程序。
- **分流随配置保留**：应用分流优先于额外规则与订阅规则，自动启用进程识别；订阅更新不会覆盖，且支持本地备份与恢复。
- **诊断更方便**：日志保留完整长消息，支持搜索、级别筛选、选择文本及复制筛选结果；设置保存失败保留草稿并显示原因。

macOS Apple Silicon（M1 及后续 M 系列）下载 `gopurr-版本-arm64.dmg`，打开后将 Gopurr 拖入 Applications。Windows 10/11 x64 下载 `gopurr-setup-版本-amd64.exe`，按向导安装。

在「设置 → 维护 → 软件更新」检查新版本。应用每天自动检查，确认后才下载和安装；更新包使用 Ed25519 签名校验。TUN 服务需在概览页安装，macOS 通过管理员密码、Windows 通过 UAC 授权；软件升级后若提示服务需要更新，点击「重新安装」。

本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 证书，系统可能提示无法验证开发者。确认下载来自本仓库后，macOS 可在「系统设置 → 隐私与安全性」允许打开，Windows 可在 SmartScreen 中查看发布信息。

`SHA256SUMS` 用于校验安装包与更新文件。`update-*.json` 和 `.tar.gz` 由应用内更新器使用，无需手动安装。
