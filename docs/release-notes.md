Gopurr 0.6.19 修复组网本机访问开关在重启后关闭的问题。

- 「允许组网设备访问本机」现在会记住你明确开启的选择。重启后，自动或手动连接组网成功时恢复已授权端口。
- 退出与断开会立即停止当前访问，但保留设置；手动关闭开关或修改端口则保存关闭状态。首次使用、登录未完成或设置保存失败时保持关闭。
- 官方网络权限、授权端口和设备封禁继续生效，更新中英文引导与授权说明。
- 更新 Brotli 与压缩依赖，修复发布扫描发现的两项可达漏洞。

**旧版本没有保存此开关状态，升级后请手动开启一次，之后重启即可恢复。** 如需应用启动后自动连接组网，请同时启用「启动 Gopurr 时自动连接组网」。

macOS Apple Silicon 下载 gopurr-0.6.19-arm64.dmg；Windows 10/11 x64 下载 gopurr-setup-0.6.19-amd64.exe。也可在「设置 → 维护 → 软件更新」检查更新，更新包通过 Ed25519 签名校验。

本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 证书，系统可能提示无法验证开发者。请确认下载来自本仓库。SHA256SUMS 用于校验下载文件。
