Gopurr 0.6.35 把桌面界面升级为「现代仪器台」：新的配色、字体节奏与浮动卡片表面，概览改为宽控制台 + 数据列的非对称布局，八个页面统一重做。

- 新调色板：浅色画布 `#eef1f6`、侧栏 `#e8ecf3`、纯白表面、强调 `#2d5fd8`；深色画布 `#08090d`、侧栏 `#0c0e13`、表面 `#12151b`、强调 `#8fb3ff`；两套调色板的所有前景/背景组合保持 4.5:1 对比度。
- 排版与密度：页标题 24/600（最小窗口 21）、分组标签 12/600、正文 13、说明 11–12.5、表头 10.5；控件 30 高、设置与分组行 50（最小窗口 46）、列表行 50–52、圆角 8/16/16，数值统一等宽数字。
- 外壳：侧栏改为强调色选中片（左缘 2.5 像素竖线、极轻投影）与底部运行状态卡片；标题栏状态胶囊 28 高并在运行时使用成功色；画布加入极淡强调色光晕，卡片使用两层柔和投影。
- 概览：桌面尺寸为宽控制台 + 窄数据列（实时速率、会话统计）的非对称布局，出口 36/600、主操作固定在控制台右上；840×560 回退为单卡片纵排，统计与四个网络控制仍在首屏。流量图悬停显示跟随指针的读数浮层，空采样轴行显示「—」。
- 八页统一：订阅当前卡片 + 分组行、代理双栏（策略组卡片 + 虚拟化节点列表与语义色延迟胶囊）、连接表 + 浮动详情卡片、规则分段标签与浮动保存条、设置 50 高设置行与浮动保存条、日志整页卡片与发丝行、组网设备卡与三步引导、软件更新弹窗。
- 新增 Lucide 图标 `server`、`radar`、`route`、`arrow-left-right`、`power`；重新生成主要桌面截图矩阵，并通过 headless 界面测试 74/74、Go 测试与构建。
