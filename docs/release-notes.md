Gopurr 0.6.63 优化了桌面侧栏切换时的右侧滑移动画，并全面升级了深浅两套界面的配色、控件质感与视觉层级。

- 侧栏收展采用 240ms 减速曲线（`[0.22, 1, 0.36, 1]`），收起时右侧内容区随不透明侧栏幕布右缘做 `184 → 0` 纯 GPU 同步滑移，顶栏导航原地微滑淡入，消除半透明叠影、左侧裁切与斜飞遮挡；展开时平滑渐显，右上内核状态胶囊固定不抖动。
- 升级深浅双色调色板与卡片表面深度：深色主按钮与开关采用高饱和钴蓝配纯白前景，重构分段选择、微标签、侧栏选中态与无边框底部摘要，去除概览、订阅、代理与组网页面的生硬左缘竖条和折边伪影。
- 统一自适应出口标题字号、对齐概览 2×2 会话统计与网络控制状态感知图标块，升级代理延迟标签；840×560 与 1060×720 明暗中英文全套界面均已重新渲染并核对。
