Gopurr 0.5.1 优化整体界面与小窗口布局，新增首页流量光轨和出口切换过渡。

- **统一空状态**：连接、规则、日志、代理、应用分流和组网采用一致的图标、说明与布局；搜索无结果时可一键重置筛选，不清除数据、不恢复已暂停的日志，也不应用未保存的草稿。
- **组网布局**：搜索与设备数量整合到同一面板，移除重复圆角边框；「准备访问」与连接操作同行，为设备、本机访问和安全设置留出更多空间。
- **设置层级**：调整分组标题、说明文字和容器间距，保留可见标签、原生控件与固定保存区。
- **首页动效**：上下行数值与曲线使用对应功能色，新增柔和光轨、最新采样点和出口切换过渡。动效只随真实数据变化，零流量不产生装饰性活动；支持系统减少动态效果，包括动画中途切换。
- **兼容性与验证**：保留中英文国际化、每订阅覆写、连接规则、连通诊断和组网安全机制；覆盖深浅色、1060×720 / 840×560、侧栏与顶部导航，补充筛选恢复和动效回归测试。

macOS Apple Silicon（M1 及后续 M 系列）下载 `gopurr-0.5.1-arm64.dmg`，打开后将 Gopurr 拖入 Applications。Windows 10/11 x64 下载 `gopurr-setup-0.5.1-amd64.exe`，按向导安装。

在「设置 → 维护 → 软件更新」检查新版本。更新包通过 Ed25519 签名校验。若提示 TUN 服务需要更新，在概览页点击「重新安装…」并完成管理员授权。

本版本尚未配置 Apple Developer ID／公证及 Windows Authenticode 证书，系统可能提示无法验证开发者。确认下载来自本仓库后，macOS 可在「系统设置 → 隐私与安全性」允许打开，Windows 可在 SmartScreen 中查看发布信息。

`SHA256SUMS` 用于校验安装包与更新文件。`update-*.json` 和 `.tar.gz` 由应用内更新器使用，无需手动安装。
