Gopurr 0.6.64 在保留右侧内容区平滑滑移与新版视觉质感的同时，恢复了导航项从左侧栏飞向顶栏的过渡动画。

- 侧栏收展时，8 个导航项重新从左侧纵列飞向顶部横排，并通过响应式宽度计算与反向文字缩放确保中英文标签全程清晰不截断。
- 保留 240ms 减速曲线（`[0.22, 1, 0.36, 1]`）、不透明侧栏幕布（带柔和右缘投影）以及右侧内容区 `184 → 0` 纯 GPU 同步滑移，消除半透明叠影穿透与左侧裁切；右上内核状态胶囊固定不抖动。
- 已重新渲染并核对 840×560 与 1060×720 下中英文明暗主题过渡帧截图。
