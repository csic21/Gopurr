# 内置 Tailscale 组网

Gopurr 内嵌 Tailscale 的 tsnet 节点，使用官方托管控制服务，不需要本机安装官方 Tailscale 客户端，也不需要自建服务器。内核来自当前 mihomo 已依赖的 `github.com/metacubex/tailscale` 固定版本；设备身份独立于其他 Tailscale 安装。登录在官方浏览器页面完成，Gopurr 不收集账号密码。

## 使用

1. 两台或更多设备在「组网」打开「连接准备」，点击「连接并登录」，分别通过官方浏览器授权加入同一个网络。授权页面出现后自动打开一次；浏览器打开失败或登录过期时可手动继续。其他设备也可以使用官方客户端。
2. 在需要被访问的设备上，选择「本机服务」或打开本机访问开关，勾选 SSH、Windows 远程桌面或 macOS 屏幕共享；自定义端口收在「自定义端口…」中。确认后才开放。Gopurr 不代替系统启动这些服务。
3. 在主动发起访问的电脑上点击「准备访问」。确认框说明 TUN、自动路由、规则模式和所需系统服务；安装由系统请求管理员授权，无需跳到概览。取消保留连接草稿，设置保存失败会尝试回滚。只接受访问的设备可跳过这一步。
4. 在设备行点击「连接」，选择 SSH、远程桌面或屏幕共享。可以记住端口与可选的 SSH 系统用户名，下次从设备行直接打开本机客户端；设备 IP 变化后使用当前网络地址。最近使用的设备排在前面。取消记忆并成功发起连接后删除旧设置。
5. 「检测连接」只按需检测当前设备的指定端口，可取消；SSH / VNC 握手标识与普通 TCP 接通分别显示，不据此承诺服务授权或登录成功。客户端未能打开时可复制地址恢复；远程桌面需要本机已安装兼容客户端。
6. 「设备 → 详情」可以修改快捷连接方式或单独封禁设备；「安全设置」可以编辑端口，以及打开官方访问策略、设备审批与设备撤销页面。托盘可以快捷连接组网或继续登录。

「启动 Gopurr 时自动连接组网」为可选项，默认关闭。启用后恢复已使用过的组网节点，不自动打开浏览器或开放本机服务；授权失效时需主动继续登录。已手动断开的组网不会在后台强制重连。

## 本机保护

- 本地访问门在网络内核启动前默认关闭；首次连接和每次重新连接均关闭。开放状态不写入磁盘，重新启动不能继承开放访问。
- 只转发明确授权的协议与端口，不支持通配符、端口范围或自动开放所有监听服务；最多 16 个服务。
- 每个入站流由内嵌节点的 WhoIs 查询取得设备稳定 ID、所属账号或标签身份；无法确认身份、目标不是本节点、端口未授权、协议不匹配或设备已封禁均拒绝。
- 官方网络 ACL/grants 与本机访问开关、端口授权、设备封禁共同生效。本机开关始终在本地执行，不依赖远端管理员修改 ACL。
- 关闭访问或封禁设备同步收回转发权限，并关闭现有 TCP / UDP 连接。后台连接或状态刷新不能推迟本地阻断。
- 授权的服务转发到 `127.0.0.1` 的同端口，包括仅监听本地的服务；请只授权有身份验证且确实需要远程访问的服务。Gopurr 不自动启动 SSH、远程桌面或共享服务，也不替代服务自身的登录保护。
- Gopurr 自身的混合代理端口禁止作为远端服务开放。临时出站桥仅监听 loopback，TCP 流和每个 UDP 数据报都使用既有 mihomo AEAD 实现与每次启动随机凭据认证，并限制目标为已知组网设备。
- 退出、崩溃或强制结束 Gopurr 后，内嵌节点与转发随进程停止。关闭窗口后应用仍在后台运行。
- 不自动配置系统 DNS、子网路由、出口节点、远端管理、Tailscale SSH、Web Client 或公网 Funnel。

这些控制针对 Gopurr 的组网服务，局域网、公网映射及其他 VPN 仍由系统防火墙和各服务管理。无法承诺软件绝对不受攻击；应同时启用官方设备审批、限制网络权限，并及时更新服务。

## 记录与身份

「本机访问」记录内嵌节点实际接收的 TCP / UDP 连接，短连接结束后仍可显示，不依赖系统 socket 采样。设备在线与实际访问分别显示。账号说明设备属于谁，不能证明键盘前的实际操作者；标签资源单独标识。

最多保留 100 条本地记录，不包含通信内容，不上传。网络层已丢弃的探测、未授权尝试、其他网络入口的连接不在该列表中；这不是完整入侵检测系统。

`mesh.json` 保存本地记录；`tailnet/access.json` 保存端口与设备封禁；`tailnet/identity.json` 保存节点密钥。身份文件和目录分别为私有权限，写入使用原子替换，不跟随已有目标链接。组网密钥、临时代理凭据及访问记录不进入配置备份。登录链接不落盘。`mesh-shortcuts.json` 只保存按设备稳定 ID 关联的连接方式、端口、可选用户名及最近使用时间；RDP 交接文件不含密码，默认关闭剪贴板、磁盘和打印机重定向，并保留服务器身份验证与登录要求。这些文件使用私有权限和原子写入，不进入配置备份。嵌入库的远程日志上传已关闭。

## 流量与能力范围

为官方控制服务提供的已知设备 IP 生成精确 `/32` 或 `/128` 规则，发送到内置的认证出站桥；这些目标留在 Gopurr TUN 内，不再排除到物理网络。不会一律绕过整个 CGNAT 或私网地址段。组网断开、设备列表或桥接凭据变化时更新运行配置。

支持按虚拟 IP 访问 TCP / UDP；内嵌节点不把其虚拟 IP 分配到宿主系统网卡。不提供局域网广播/多播发现、系统 ICMP 转发、子网中继或出口节点。Tailscale 节点自身可能回应网络诊断，但不能据此判断本机服务已经开放。MagicDNS 不接管系统解析，当前入口使用设备 IP。

## 验证范围

本地测试覆盖真实 mihomo 出站与内置桥互通、错误密钥和未知设备拒绝、真实 loopback TCP / UDP 服务转发、端口和协议约束、未知身份拒绝、设备封禁、已有流立即撤销、短连接记录、重启默认关闭、私有密钥存储与坏文件拒绝，以及路由、引导、取消恢复、网络准备回滚、快捷交接文件、地址更新、自动连接偏好和 UI 交互。测试的身份 API 使用本地夹具；不登录真实 Tailscale 账号、不改变系统代理或真实 TUN。

UI 截图覆盖明暗主题、两种导航以及 1060×720 / 840×560；设备详情、服务预设、连接准备、快捷窗口、检测、封禁、登录与错误状态均有夹具。应用包包含内嵌节点，无需独立客户端。

官方账号授权、异地两台及更多真实设备互访、NAT 穿透/中继与 Windows 原生运行仍需实机验收；本地测试不能代替这些验证。
